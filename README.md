# 📦 Inventory Management System

A full-stack project that includes:
- ✅ A MySQL relational database for managing inventory data
- ✅ A CRUD API built using [FastAPI / Node.js + Express] to interact with the database

---

## 🛠️ Features

- Manage products (add, update, delete, list)
- Track inventory levels
- Associate suppliers and product categories
- Clean database design with proper relationships
